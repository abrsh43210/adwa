# CryptoScript Bot (Android)

An Android application built with Kotlin and Jetpack Compose, rewritten from the imported `abrsh43210/adwa` web landing page.

## Features

- Native Jetpack Compose welcome screen (`Welcome to CryptoScript Bot` and `Your ultimate companion for cryptocurrency insights.`)
- Material Design 3 theming with adaptive light/dark color schemes and bundled Space Grotesk & Plus Jakarta Sans typography
- Edge-to-edge layout with safe drawing insets and responsive layout adaptation for compact and expanded screen widths
- Custom adaptive launcher icon and hero banner illustration
